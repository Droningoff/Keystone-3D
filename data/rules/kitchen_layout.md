# Правила раскладки кухни (Самолет) для агента ИИ

## Стены

- Буквы: **A** задняя (z=0), **B** правая (x=L), **C** передняя (z=D), **D** левая (x=0).
- По часовой: A → B → C → D. Код: `furniture_constructor/js/walls.js`.
- Offset вдоль стены: от начала стены (см. поле `from` у стены) к концу, мм.
- Модуль «смотрит» фасадом в комнату: у A rot=0, у B rot=270 (−90), у C rot=180, у D rot=90.

## Формы

- **Линейная** — один ряд по `mainWall`.
- **Угловая (L)** — ряды по `mainWall` и `secondWall`, стык в `corner` (A–D / A–B / …). Угловой модуль или стык бок о бок без щели > 2 мм.
- **П-образная** — три стены; четвёртая обычно с дверью.

## Ряды

- Нижний ряд: категории «Нижние», пеналы с краю. Подъём корпуса ~100 мм (ножки в фурнитуре).
- Верхний ряд: «Навесные», elev ≈ 1450 (или под потолок по высоте модуля). Над варочной — место под вытяжку / низкий шкаф.
- Заполнять стену **целиком** по ТЗ («вдоль всей стены A»), минус проёмы с зазором ≥ 50 мм от двери/окна до корпуса.

## Подбор ширины

1. Измерить свободный пролёт стены (длина − уже занятое − зазоры у проёмов).
2. Набрать сумму ширин из доступных `w` серии (предпочтительно 600, 800, 450, 400, 300, 200, 150).
3. Не оставлять остаток 1…100 мм: пересобрать набор.
4. Один **decor** на весь проект (по умолчанию KF). Предпочитать `geom: full`.

## Функции (серии Самолет, ориентиры)

| Функция | Серии (ориентир) | Ширина типичная |
|---------|------------------|-----------------|
| Тумба двери | Н-КЗ | 400–600 |
| Ящики | Н-ЯЩ | 400–600 |
| Мойка | Н-КМ | 600–900 + fixture sink/mixer |
| Духовка/ниша | Н-ДО | 600 |
| Бутылочница | Н-КБ / ВКБС | 150–200 |
| Пенал | Н-ХД, П-ПД (антресоль) | 600 |
| Навесной 1 дверь | В-К1 | по ширине низа |
| Навесной 2 двери | В-К2 | 600–900 |
| Угол / Г-стык | Н-КУ, Н-КУ70 | 900–1200 |

Уточнять артикул только по `data/samolet/index.json`.

## Техника

- Мойка и смеситель — в модуль мойки, по центру.
- Варочная — в столешницу над тумбой 600 (часто над духовкой Н-ДО).
- Вытяжка — под навесным над варочной или отдельно.
- Не ставить ящичный модуль под мойку.

## Пенал

- «Справа» = в конце ряда по направлению offset основной стены (больший offset).
- «Слева» = в начале (offset 0).
- Антресоль П-ПД — над пеналом (elev ≈ 2140).

## Выход агента

1. Список: стена, offset, артикул, роль.
2. Обновить JSON проекта / файл в `furniture_constructor/work/`.
3. Что проверить в UI (пересечения, проёмы, фасады).
