# Keystone-3D

Репозиторий тестовой версии 3D-планировщика корпусной мебели и интерьеров.

## Вход (мягкая авторизация)

При открытии сайта показывается экран входа. Это **мягкий** режим без сервера: удобство для сотрудников, не криптостойкая защита.

Стартовые учётки (`data/users.json`):

| Логин | Пароль | Роль |
|-------|--------|------|
| `admin` | `admin123` | администратор |
| `user` | `user123` | пользователь |

После первого входа смените пароль admin в **Админ-панели**.

Сессия хранится в `sessionStorage` (сбрасывается при закрытии вкладки).

### Админ-панель

Ссылка «Админ» в шапке (только для роли admin) → `admin.html`:

- пользователи: создать / пароль / роль / вкл-выкл;
- настройки сайта: пути Базиса, свет по умолчанию, видимость вкладок;
- «Скачать *.json» — выгрузка для выкладки в `data/` на сервере (иначе overrides только в этом браузере).

## Мои объекты (свои 3D-модели OBJ)

Вкладка «Помещение» → блок «Мои объекты»:

- «Загрузить OBJ…» — `.obj` вместе с `.mtl` и текстурами или один `.zip` (до 50 МБ). В карточке перед сохранением: название, категория, единицы файла (мм/см/м/дюймы), ось «вверх» (Y — Базис, Z — 3ds Max/SketchUp), посадка (пол/стена), цвет.
- Модель хранится нормализованной (мм, Y вверх, низ на полу, центр по X/Z) в IndexedDB браузера, отдельно для каждого логина.
- Карточка: клик — поставить на сцену; «Заменить» — новая модель (экземпляры на сцене сохраняют свой масштаб); «В архив» / «Вернуть»; «×» — удалить (вместе с экземплярами на сцене).
- «Выгрузить каталог» / «Загрузить из файла» — перенос каталога между браузерами и компьютерами (`*.ks3dobj.json`).
- На сцене: X/Z/высота/поворот, габариты с замком пропорций, масштаб %, зеркально, свой цвет, «На пол», «К стене», «Исходный размер».
- OBJ из фрагмента Базиса: «Файл → Экспорт» или скрипт `tools/bazis-export-fr3d-obj.js` (пакетно .fr3d → .obj).

## План помещения («План от точки…»)

- Двойной клик по размеру стены — длина и название; переключатель «начало / оба / конец» задаёт, какой конец стены сдвинуть.
- Двойной клик по углу — точное значение (есть быстрые 45…270°); дугу угла можно тянуть мышью (шаг 15°, с Alt — 1°).
- Стены нумеруются по ходу обхода, буквы совпадают с 3D. Своё название стены видно и на сцене.
- У стен постоянные id: после «Применить» окна, двери и цвета остаются на своих стенах, мебель и конструкции сдвигаются вместе с планом.
- Правка пола переносится на остальные уровни (потолок, столешница) с сохранением их наклона.
