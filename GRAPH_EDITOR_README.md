# Графовый редактор помещения

## Описание

Новый гибкий редактор на основе графовой модели данных. Позволяет рисовать стены от любой вершины в любом направлении.

## Особенности

- **Свободное рисование**: клик по вершине → рисование от неё в любом направлении
- **Отображение углов**: углы показываются между всеми стенами у каждой вершины
- **Snap к осям**: автоматическое выравнивание по горизонтали/вертикали (0°/90°/180°/270°)
- **Нет требования замыкания**: можно рисовать открытые цепочки стен
- **Гибкая структура**: стены не обязательно должны быть последовательными

## Архитектура

### Модель данных

```javascript
{
  vertices: [
    { id: 'v0', x: 0, z: 0 },
    { id: 'v1', x: 3000, z: 0 },
    { id: 'v2', x: 3000, z: 2000 }
  ],
  edges: [
    { id: 'e0', from: 'v0', to: 'v1', len: 3000, lock: false },
    { id: 'e1', from: 'v1', to: 'v2', len: 2000, lock: false }
  ]
}
```

### Файлы

- `roomGraph.js` — модель данных и функции работы с графом
- `planEditorGraph.js` — UI редактора
- `test_graph_editor.html` — тестовая страница

## Использование

### Тестирование

Откройте: http://127.0.0.1:8080/test_graph_editor.html

### Workflow

1. **Рисование первой стены**
   - Клик в пустое место → создание стартовой вершины
   - Движение мыши → rubber line показывает будущую стену
   - Клик → создание стены и новой вершины
   - Автоматически продолжаем от новой вершины

2. **Рисование от произвольной вершины**
   - Esc → завершить текущее рисование
   - Клик по существующей вершине → начать рисование от неё
   - Движение мыши в любом направлении
   - Клик → создание новой стены

3. **Пример: П-образная комната**
   ```
   Шаг 1: Рисуем стену A-B (3000 мм, горизонтально)
   Шаг 2: Esc → завершаем
   Шаг 3: Клик по вершине B
   Шаг 4: Рисуем стену B-C (2000 мм, вертикально вниз)
   Шаг 5: Esc → завершаем
   Шаг 6: Клик по вершине A
   Шаг 7: Рисуем стену A-D (2500 мм, вертикально вниз)
   Результат: 3 стены, без замыкания
   ```

### Управление

- **Клик** — поставить стену / выбрать вершину
- **Alt + движение** — свободный угол (без snap)
- **Esc / ПКМ** — завершить рисование
- **Backspace** — удалить последнюю стену
- **Колесо мыши** — масштаб
- **Перетаскивание фона** — панорамирование

### Ввод точных значений

- Поля "Длина" и "Угол" в панели слева
- **Enter** — применить и поставить стену
- **Tab** — переключение между полями

## Интеграция

### Конвертация из старой модели

```javascript
import { chainToGraph, graphToChain } from './js/roomGraph.js';

// Старая модель → граф
const graph = chainToGraph(oldChain);

// Граф → старая модель (для совместимости)
const chain = graphToChain(graph);
```

### Использование в коде

```javascript
import { openPlanEditorGraph } from './js/planEditorGraph.js';

openPlanEditorGraph({
  chain: existingChain, // опционально
  wallThick: 100,
  onApply: (result) => {
    console.log('Вершины:', result.vertices);
    console.log('Рёбра:', result.edges);
    console.log('Chain:', result.chain); // для совместимости
  },
  onCancel: () => {
    console.log('Отменено');
  }
});
```

## Отличия от старого редактора

| Старый редактор | Новый редактор |
|----------------|----------------|
| Последовательное рисование | Свободное рисование от любой вершины |
| Требует замыкания контура | Замыкание опционально |
| Углы только между соседними стенами | Углы между всеми стенами у вершины |
| Линейная структура | Графовая структура |
